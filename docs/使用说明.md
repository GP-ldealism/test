## 0. 三种场景速查

| 想做什么 | 命令 | 需要什么 |

## 2. 单图修复（Gradio 界面）

```powershell
.\start_ui.ps1          # 或：python -m app.ui
```

浏览器打开 `http://127.0.0.1:7860`。

**操作步骤**

1. 「载入本地示例图片」或上传自己的图（会统一转成 256×256 RGB）；
2. 用画笔涂抹要修复的区域；或把「掩码来源」切成「上传掩码」，白色=修复、黑色=保留；
3. 点「预览修复区域」确认（左侧显示遮挡后的输入，右侧显示实际修复区域）；
4. 选预算 `K=2/5/8`（默认 5）、填随机种子（默认 42），点「开始修复」；
5. 结果图与 `config.json` 可在页面下载。GPU 请求串行排队，运行中不能取消。

**输出位置**：`results/ui/<YYYYMMDD_HHMMSS>_<8位id>/`，含 `original.png`、`mask.png`、`input_preview.png`、`result.png`、`config.json`（NFE、耗时、峰值显存、缺失面积）。该目录按 `.gitignore` 不入库。

**界面已知限制**：不展示 PSNR/LPIPS（上传图没有参考答案）；全缺失掩码会被拒绝；未涂抹任何区域时直接返回原图。

## 3. 批量实验

### 3.1 输入与策略

- 清单粒度：`原图 × 掩码类型 × 目标面积`，共 50 图 × 3 类掩码 × 2 种面积 = 300 行；
- 划分：`check`（10 图）/ `dev`（10 图）/ `test`（30 图），按清单顺序取原图，划分只依赖原图；
- 每个样本跑 `K=2/5/8` 三档各一次，六条策略（B1/B2/B3/M1/A1/C1）复用同一次推理结果，不产生额外推理；
- 等预算约束：低/高各占 `floor(N/3)`、其余中档，因此总 NFE 与全 K=5 相同。

### 3.2 常用命令

```powershell
$py = 'D:\Study\Postgraduate\GPT\envs\lanpaint\Scripts\python.exe'

# 开发集 + 冻结规则（会写 frozen_policy.json，不覆盖已存在文件）
& $py scripts\run_experiment.py --config configs\dev.yaml --split dev --freeze-development --warmup

# 主测试（测试集必须给冻结配置）
& $py scripts\run_experiment.py --config configs\main.yaml --split test `
      --image-limit 30 --target-area 0.30 --frozen-policy <冻结json> --warmup `
      --report results\main_test_report.json

# 面积扩展 / 重复实验（必须给主测试输出目录作为基准）
& $py scripts\run_experiment.py --config configs\area.yaml --split test `
      --image-offset 0 --image-limit 10 --target-area 0.15 `
      --baseline-run <主测试输出目录> --frozen-policy <冻结json>
```

### 3.3 关键参数

| 参数 | 作用 |
|---|---|
| `--config` | 实验 YAML（`configs/{dev,main,area,repeat}.yaml`），相对路径按项目根解析 |
| `--split` | `check` / `dev` / `test`，一次只能一个划分 |
| `--image-offset` / `--image-limit` | 取清单里的第几段原图 |
| `--target-area` / `--mask-type` | 可重复传，过滤面积与掩码类型 |
| `--frozen-policy` | 冻结 JSON；含 `test` 样本时必填 |
| `--baseline-run` | 面积/重复实验必填，指向已完成的主测试输出目录 |
| `--freeze-development` | 完整开发集跑完后选权重、拟合阈值并冻结 |
| `--warmup` | 计量前跑一次中预算预热，单独记录、不计入结果 |
| `--policies` | 逗号分隔，只跑指定策略 |
| `--report` | 额外把报告 JSON 写到指定路径 |

### 3.4 产物与怎么读

```
results/raw/<experiment_id>/seed_<seed>/<run_id>/
├─ config.yaml  manifest.csv  selection.json      # 本次跑什么
├─ samples.csv  tier_results.csv                  # 逐样本策略记录 / 三档原始结果
├─ run_log.jsonl  failures.jsonl                   # 逐事件日志 / 失败明细
├─ source_provenance.json  source_snapshot.zip     # 源码指纹与快照
├─ frozen_policy.json  input_hashes.json          # 冻结规则与输入哈希
├─ report.json                                     # 汇总报告
└─ images/                                         # 结果 PNG（不入库）
results/metrics/<experiment_id>/seed_<seed>/<run_id>/
├─ per_sample.csv  per_image.csv  summary.csv
└─ budget_quality.csv
```

`report.json` 里三个字段决定结果能不能用：

- `status=ok` 且 `num_failures=0`：没有样本失败；
- `comparison_complete=true`：所有样本三档都成功，可以比较；
- `equal_nfe=true`：B2/M1/A1/C1 的实际累计 NFE 相等。**只有它为真才是严格等预算对照**；从大运行里截子集时它不自动成立。

### 3.5 中断与重跑

同一条命令重跑即可：已完成的「图片 + 掩码 + 种子 + 档位」会命中 `data/_cache/results/` 的缓存，不重复推理。缓存键包含代码指纹、权重哈希、图片/掩码哈希、种子、精度、K、外层步数与全部采样参数——**改了代码或参数就不会误用旧结果**。

## 4. 评价与离线分析

```powershell
# 单次运行的三项指标（缺失区 PSNR / 全图 LPIPS / 边界带 MAE）
& $py scripts\evaluate.py --exp s1_smoke
& $py scripts\evaluate.py --raw-dir results\raw\<exp> --reference <原图> --mask <掩码> --out results\metrics\<exp>

# 开发集：质量—成本图 + 逐样本预算收益 + 分析 Markdown
& $py scripts\analyze_development.py --run-dir <开发集运行目录>

# 失败诊断与案例图（10 组，含 5 组退化）
& $py analysis\diagnose_budget.py --cases-per-side 5
```

`diagnose_budget.py` 的额外参数：`--dpi`（默认 140，归档用 100）、`--palette`（0=关闭，归档用 256）、`--out`。仓库内现有图表就是用 `--cases-per-side 5 --dpi 100 --palette 256` 生成的（13.3 MB → 3.0 MB）。

**注意**：该脚本依赖本地原图与各运行的 `images/`（都不入库），因此**在干净克隆里跑不了**，只能在本机工作区运行；它也不会改动 `app/`、`scripts/` 或冻结配置。

## 6. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `未找到模型权重：…` | 权重未下载 | 按[上游溯源](上游溯源.md)下载并核对 SHA-256 |
| `实际源码与开发集冻结版本不一致` | `app/`、`scripts/` 或 `requirements*.txt` 与冻结时不同 | 恢复源码；确需修改则登记新版本并重做开发集冻结，**不要手工改哈希** |
| `测试集必须指定 frozen_policy 冻结配置` | 漏传 `--frozen-policy` | 补参数 |
| `面积/重复实验必须指定种子 42 主测试的 baseline_run` | 漏传 `--baseline-run` | 补参数，指向主测试 `report.json` 里的 `output_dir` |
| `图片内容与清单 SHA-256 不符，请重新准备清单` | 原图被替换/重新生成 | 重跑 `prepare_samples.py` 并核对 `data/manifest.csv` 未被意外改写 |
| `未检测到可用的 NVIDIA GPU…` | 环境无 GPU 或装的是 CPU 版 torch | 换用 GPU 环境；界面需要真实 GPU |
| `显存不足，请关闭占用 GPU 的程序后重试` | 其他进程占用显存 | 关闭占用；保持 `batch_size=1` |
| `Missing AlexNet weights…`（`ci/run_cpu_tests.py`） | 本机没有 LPIPS 权重 | 先在线执行一次 `python -c "import lpips; lpips.LPIPS(net='alex', verbose=False)"` |
| `CPU check sees N CUDA device(s)` | CUDA 屏蔽未生效 | 确认通过 `ci/run_cpu_tests.py` 启动，不要手工改环境变量 |
| 界面打不开 / 端口占用 | 7860 被占用；`check_ui.py` 用 7862 | 关闭占用进程后重启 |
| `请保留一部分原图；当前版本不支持整张图片全部遮挡` | 掩码覆盖全图 | 减少涂抹区域 |

## 7. 哪些东西不入库

`checkpoints/`、`third_party/LanPaintBench/`、`data/samples/original/`、`data/_cache/`、`results/raw/**/images/`、`results/ui/`、`.cache/`。其余（清单、掩码、指标 CSV、报告、案例图、源码快照）都应提交——它们是可复现的证据。
