## 4. 环境与偏差说明

- **依赖版本**：干净环境按 `ci/requirements.txt` 安装，关键版本 `torch 2.11.0+cpu`、`torchvision 0.26.0+cpu`、`numpy 2.3.2`、`pandas 2.3.3`、`gradio 5.50.0`、`lpips 0.1.4`、`matplotlib 3.10.5`、`pytest 9.2.0`、`ruff 0.17.4`，与开发机逐一对应。
- **GPU 步骤的解释器**：第 8–10 步复用本机既有 lanpaint 环境（`torch 2.11.0+cu128`）。CI 用的 CPU 轮子无法做 GPU 推理，本轮未新建 CUDA 版环境（需重新下载约 2.5 GB 轮子）；这是已知偏差，不改变"代码在干净克隆中可运行"的结论。
- **AlexNet 权重**：第 5、6 步命中本机 `~/.cache/torch/hub/checkpoints/alexnet-owt-7be5be79.pth` 缓存；全新机器需先在线下载一次，`ci/run_cpu_tests.py` 会在缺失时明确报错而不是静默联网。
- **目录联接**：权重与上游用 junction 指向本机副本，避免复制 2.2 GB；删除临时目录时先移除联接再删父目录，本机副本未被改动。
